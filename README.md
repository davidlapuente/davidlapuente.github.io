# David Lapuente — Página de enlaces

Página estática sencilla tipo "link in bio" con los enlaces principales de David Lapuente Romero, diseñador web sénior.

## Contenido del repositorio

- `index.html` — página principal con los tres enlaces.
- `foto.png` — foto de perfil usada en la página.
- `thumbnail.png` — miniatura/imagen de vista previa al compartir el enlace.

## Enlaces incluidos

- LinkedIn: [linkedin.com/in/lapuenteromerodavid](https://www.linkedin.com/in/lapuenteromerodavid/)
- Web: [davidlapuente-design.lovable.app](https://www.davidlapuente-design.lovable.app) 
- Portfolio: [david-lapuente-romero-jemrrlc.gamma.site](https://david-lapuente-romero-jemrrlc.gamma.site/)
- Landing: [web-de-alta-conversion-6fyh7e5.gamma.site/landing-page](https://web-de-alta-conversion-6fyh7e5.gamma.site/landing-page)

## Publicación

Pensada para servirse como página estática, por ejemplo mediante GitHub Pages, apuntando a la rama principal del repositorio.
