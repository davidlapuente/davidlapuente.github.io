# David Lapuente — Página de enlaces

Página estática sencilla tipo "link in bio" con los enlaces principales de David Lapuente Romero, diseñador web sénior.

## Contenido del repositorio

- `index.html` — página principal con los tres enlaces.
- `foto.png` — foto de perfil usada en la página.
- `thumbnail.png` — miniatura/imagen de vista previa al compartir el enlace.

## Enlaces incluidos

- LinkedIn: [linkedin.com/in/lapuenteromerodavid](https://www.linkedin.com/in/lapuenteromerodavid/)
- Web: [davidlapuente.lovable.app](https://www.davidlapuente.lovable.app) 
- Portfolio: [https://portfolio-web-directa-jemrrlc.gamma.site/portfolio-david-lapuente](https://portfolio-web-directa-jemrrlc.gamma.site/portfolio-david-lapuente)
- Landing: [https://landing-page-8113aql.gamma.site/landing-web-directa](https://landing-page-8113aql.gamma.site/landing-web-directa)
- Reseñas de Google: enlace corto de Google (share.google)

## Publicación

Pensada para servirse como página estática, por ejemplo mediante GitHub Pages, apuntando a la rama principal del repositorio.

Esta página es independiente del sitio web completo de marca personal, que se gestiona por separado en Lovable (`davidlapuente-design.lovable.app`).
